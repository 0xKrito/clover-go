# 01 - CloverGo 产品需求与业务状态矩阵规格书 (PRD)

> **产品定位**：基于 **`github.com/egoist/mygo` (v0.7.1 Metal GPU 原生界面 + `CGO_ENABLED=0` 纯 Go 全栈)** 构建的 macOS 原生多标签文件管理器。
> **核心理念**：「**看起来是克制优雅的原生 Mac 应用，用起来是行云流水的 Windows Clover**」——以单一 Go 语言栈彻底终结 `SwiftUI + Rust (C FFI)` 双语言维护成本，实现 **<16MB 单二进制、~35MB 常驻内存、0% 空闲 CPU、120Hz Metal GPU 瞬时响应**。

---

## 一、 事前：需求漏洞四维雷达体检 (Pre-Implementation Audit)

根据全局架构与产品红线，对「从 `fclover (SwiftUI+Rust)` 迁移至 `CloverGo (MyGo 纯 Go)`」进行四维体检：

```text
┌───────────────┬────────────────────────────────────────────────────────────────────────────────────────┐
│ 漏洞检测项    │ 质询、审查结论与工程对策                                                               │
├───────────────┼────────────────────────────────────────────────────────────────────────────────────────┤
│ ① 背景与目标  │ 真实诉求并非“重写一套功能更多的全家桶”，而是：                                         │
│   (XY 问题)   │ 1. 消除 Rust+Swift 双工具链与 FFI 维护负担，收敛为 100% 纯 Go (`CGO_ENABLED=0`)；      │
│               │ 2. 用 MyGo Metal GPU + Apple HIG 视觉体系做出超越旧版的原生 Mac 精致感与极致低耗。     │
├───────────────┼────────────────────────────────────────────────────────────────────────────────────────┤
│ ② 隐式假设    │ 1. 大目录规模：Downloads / node_modules 可能含 10,000~100,000 个条目；                 │
│               │ 2. 渲染帧预算：120Hz 下单帧仅 8.3ms，渲染函数 `View(c)` 内必须 **0 磁盘/系统调用**；   │
│               │ 3. 多窗口独立：每个窗口拥有独立 `WindowSession` 与当前激活 Tab，绝不跨窗串改路径。     │
├───────────────┼────────────────────────────────────────────────────────────────────────────────────────┤
│ ③ 逆向与异常  │ 1. 权限受限目录（如 `/System` 或未授权目录）：禁止静默空白，内联展示权限提示与重试；   │
│               │ 2. 文件复制/移动同名冲突：提供「覆盖 / 跳过 / 自动重命名(file 2.ext) / 应用到剩余」；  │
│               │ 3. 外部删除当前所在目录：FSEvents 感知后自动回退至最近存在的父目录或家目录 `~`；       │
│               │ 4. 高频连点/快速切 Tab：引入请求代数 (`loadGen uint64`) + `context.CancelFunc` 丢弃旧帧│
├───────────────┼────────────────────────────────────────────────────────────────────────────────────────┤
│ ④ 业务矛盾    │ 1. `⌘+点击` 冲突：Finder 用 `⌘+点击` 做离散多选，浏览器用它开新标签。                  │
│               │    ➔ 决策：严格保持 Finder 多选习惯；开新标签统一用 **中键点击 / `⌥+点击` 文件夹**。   │
│               │ 2. 空格键冲突：重命名输入框或搜索框聚焦时按 `Space` 必须输入空格，严禁误触 Quick Look。│
└───────────────┴────────────────────────────────────────────────────────────────────────────────────────┘
```

## 二、 核心产品能力域拆解（6 大模块）

### 2.1 模块一：Clover 灵魂多标签与多窗口系统 (`tab` & `window`)
1. **页感衔接标签栏**：活动标签与下方工具栏/内容区视觉同色连通，支持水平滚动与自适应压缩。
2. **标签核心操作**：
   - 新建标签 (`⌘T`，默认继承当前目录或偏好目录)、关闭标签 (`⌘W`)、切换标签 (`⌃⇥` / `⌃⇧⇥` / `⌘1~9`)。
   - **固定标签 (Pin Tab)**：右键固定后仅显示紧凑文件夹图标，禁止误关 (`⌘W` 跳过)。
   - **关闭栈恢复 (`⇧⌘T`)**：每个窗口维护容量为 20 的 LIFO 关闭栈，一键恢复刚关掉的目录与滚动位置。
   - **中键 / `⌥+点击` 文件夹**：在当前标签右侧后台/前台打开新标签；拖拽文件夹到标签栏直接打开对应标签（若同路径已打开则直接聚焦）。
   - **同名目录消歧副标题**：当两个标签目录同名（如两个 `src`）时，自动显示父目录名作为副标题（如 `src — projectA`）。
3. **跨窗口拖出与合并**：
   - **拖出成窗 (Detach)**：将标签拖出当前窗口边界释放，自动在鼠标落点创建独立 MyGo 窗口并移交该 `TabState`。
   - **拖回合并 (Merge)**：将标签拖入另一窗口的标签栏，合并进目标窗口；若源窗口已无剩余标签则自动销毁源窗口。
4. **会话恢复与命名工作区 (`Workspace`)**：
   - 退出/重启自动恢复上次活动标签与固定标签；支持将当前一组标签保存为「命名工作区」（如“Go 研发”、“日常归档”），一键切换整套目录上下文。

### 2.2 模块二：Finder 级双模文件浏览引擎 (`browser`)
1. **列表视图 (`ui.Table` / `ui.List`)**：
   - 固定四列：**名称（含原生图标 + 颜色标签圆点）**、**修改日期**、**大小**、**类型**。
   - 点击列头升/降序排序：**修改日期排序混排文件与文件夹**；名称、大小、类型排序保持**文件夹优先**（自然序大小写不敏感）。
   - 支持行内拖拽多选 (`DragSelect`)、`⌘` 离散多选、`⇧` 范围多选、双击进入目录/打开文件、`⌘↓` 打开、`⌘↑` 返回上级。
2. **图标网格视图 (`ui.GridView`)**：
   - 基于 `mygo/ui` 原生虚拟化网格，百万级条目仅渲染视口内行，支持底部/状态栏滑块动态调节图标尺寸（`64px ~ 128px`）。
   - 支持二维方向键导航、首字母快速定位、框选/拖拽多选、图片实时缩略图与系统高清图标展示。
3. **路径优先工具栏与智能导航**：
   - 前进 / 后退历史栈（独立于每个 Tab）、上级目录按钮。
   - **路径面包屑**：优先占据横向空间，默认折叠 `/Users/<username>` 为 `~`（带家目录图标），点击任意面包屑节点直达对应父目录；双击空白处或按 `⌘L` / `⇧⌘G` 切换为可编辑路径输入框。
   - **当前目录实时过滤 & 深度搜索 (`⌘F`)**：输入即按 Token 评分搜索（支持多词匹配、前缀/子串加权、内存索引 TTL 缓存）。

### 2.3 模块三：可信文件操作与冲突闭环 (`fsops`)
1. **基础工作流**：复制 (`⌘C`)、剪切 (`⌘X`)、粘贴 (`⌘V`)、移入废纸篓 (`⌘⌫`，调用 `mygo.Shell.TrashItem`)、新建文件夹 (`⇧⌘N`)、创建副本 (`⌘D`)。
2. **重命名体系**：
   - 单文件回车 (`Return`) 进入内联重命名（自动选中文件名主干，跳过扩展名）。
   - 多文件选中按 `⇧⌘R` 弹出**批量重命名弹窗**，支持 4 种模式：**序号递增、添加前缀、添加后缀、查找替换**，底部实时预览全部新旧文件名对比。
3. **冲突处理状态机**：
   - 粘贴或拖拽遇到同名文件时，绝不静默覆盖或报错中断，弹出冲突决策框：**覆盖 (Overwrite) / 跳过 (Skip) / 保留两者 (`file 2.ext`)**，并支持勾选「应用到剩余冲突项」。
4. **归档与路径工具**：
   - 右键支持「压缩为 `.zip`」与双击/右键解压（底层调用 macOS 原生 `/usr/bin/ditto -c -k --sequesterRsrc`，完美保留 Mac 资源分叉与中文编码）。
   - 一键复制路径三件套：**POSIX 绝对路径**、`~/...` 简写路径、`file://` URL。

### 2.4 模块四：双轨预览系统 (`preview`)
1. **右侧常驻预览栏 (`⇧⌘P`)**：
   - 位于主内容区右侧（可通过 `ui.Split` 调节宽度或一键收起）：
   - **图片文件**：高清缩放预览 + 分辨率信息；
   - **代码/文本/Markdown**：直接复用 `mygo/ui/editor`（只读代码高亮视图）与 `mygo/ui/markdown` 渲染前 64KB 内容；
   - **通用元数据区**：高清大图标、文件名、完整路径、大小（目录支持异步计算总大小）、创建/修改时间、读写权限、**Finder 7 色标签快捷点选器**。
2. **空格键系统 Quick Look (`Space`)**：
   - 选中任意文件（视频、PDF、Office、音频、设计稿）按 `Space`，拉起 macOS 原生 Quick Look 预览窗，再按 `Space` 或 `Esc` 关闭，方向键实时跟随切换预览项。

### 2.5 模块五：macOS 深度系统联动 (`integration`)
1. **Finder 互通 7 色标签**：直接通过 `unix.Getxattr` / `unix.Setxattr` 读写 `com.apple.metadata:_kMDItemUserTags`（二进制 plist 格式），与系统访达 100% 双向实时互通（红/橙/黄/绿/蓝/紫/灰）。
2. **外部工具一键联动**：右键或工具栏支持「在终端中打开」（自动识别 Terminal / iTerm2 / Ghostty / Warp）、「在编辑器中打开」（VS Code / Cursor / Zed / Antigravity）、「打开方式」子菜单。
3. **从 Finder 进入 CloverGo**：支持 `fclover://open?path=...` 与 `fclover://reveal?path=...` 深链协议，配套一键安装 macOS Finder 服务菜单（右键「在 CloverGo 中打开」）。

### 2.6 模块六：侧边栏、书签栏与原生主题定制 (`workspace & theme`)
1. **毛玻璃侧边栏 (`Vibrancy`)**：分组展示「系统个人收藏」（个人、桌面、文稿、下载、应用程序）、「自定义收藏夹」（支持拖拽文件夹加入/排序）、「挂载卷/外部磁盘」（实时探测 `/Volumes`）与「命名工作区」。
2. **顶部书签栏 (`⇧⌘B` 显隐)**：类似 Chrome 书签栏，高频目录一键直达。
3. **Apple HIG 原生双模主题**：继承并在 `roxy/mygo-app` 基础上升级——支持跟随系统 / 浅色 / 深色模式、9 种 Apple 原生强调色切换、窗口 `NSVisualEffectView` 毛玻璃穿透开关。

## 三、 纯业务状态流转矩阵 (Business State Matrix)

杜绝任何悬空状态与静默失败，核心业务流转定义如下：

```text
┌──────────────────────┬────────────────────┬────────────────────┬──────────────────────────────┬────────────────────────────────┐
│ 触发事件             │ 前置状态           │ 后置状态           │ 伴随副作用                   │ 异常 / 失败降级分支            │
├──────────────────────┼────────────────────┼────────────────────┼──────────────────────────────┼────────────────────────────────┤
│ 点击目录 / 面包屑 /  │ Tab 处于 `Idle` 或 │ Tab 进入 `Loading` │ 1. `loadGen++` 取消上一次请求│ 路径不存在或无权限：           │
│ 前进后退             │ 上一次 `Loading`   │ (首屏 >60ms 才显   │ 2. 推入前进/后退历史栈       │ Tab 转入 `ErrorState`，展示    │
│                      │                    │ 骨架/加载指示)     │ 3. 切换 `Watcher` 监听目标   │ 权限/路径报错卡 + [返回上级]   │
├──────────────────────┼────────────────────┼────────────────────┼──────────────────────────────┼────────────────────────────────┤
│ 后台目录读取完成     │ Tab 处于 `Loading` │ Tab 转为 `Ready`   │ 1. `RunOnMain` 原子替换切片  │ 若返回时 `gen != currentGen`： │
│ (分页首屏 / 全量)    │ 且 `gen` 匹配      │                    │ 2. 投递可视区图标/缩略图任务 │ 直接丢弃过期结果，零 UI 抖动   │
├──────────────────────┼────────────────────┼────────────────────┼──────────────────────────────┼────────────────────────────────┤
│ 粘贴 (`⌘V`) / 拖拽   │ 剪贴板非空，目标   │ 1. 无冲突：`Busy`  │ 后台协程执行 copy/move；     │ 磁盘满 / 源被删 / 权限拒绝：   │
│ 释放文件到目录       │ 目录可写           │ 2. 有冲突：弹窗等待│ 完成后触发目标目录 `SoftReload`│ 弹出红色 `Toast` 详情，已成功  │
│                      │                    │    `ConflictModal` │ 并自动高亮选中新生成的文件   │ 的保留，失败项保留剪贴板       │
├──────────────────────┼────────────────────┼────────────────────┼──────────────────────────────┼────────────────────────────────┤
│ 删除文件 (`⌘⌫`)      │ 至少选中 1 个条目  │ 执行中 `Busy` ➔    │ 调用 `mygo.Shell.TrashItem`  │ 外置盘不支持废纸篓或权限不足： │
│                      │                    │ 完成后 `Ready`     │ 成功后选中焦点顺移至相邻项   │ 弹出确认框询问是否永久删除或报错│
├──────────────────────┼────────────────────┼────────────────────┼──────────────────────────────┼────────────────────────────────┤
│ 拖出标签至窗口外释放 │ 窗口含 ≥1 个标签   │ 源窗口移除该标签， │ 在释放坐标 `mygo.NewWindow`  │ 若源窗口仅剩 1 个标签：        │
│ (`Escaped == true`)  │                    │ 新窗口挂载该标签   │ 创建新窗口并转移 `TabState`  │ 禁止拆出新窗，直接移动当前窗口 │
├──────────────────────┼────────────────────┼────────────────────┼──────────────────────────────┼────────────────────────────────┤
│ FSEvents 监听到外部  │ Tab 处于 `Ready`   │ 触发防抖 (150ms)   │ 保持当前滚动条位置与已有选中 │ 若当前目录本身被外部删除：     │
│ 文件增删改           │                    │ `SoftReload`       │ 集合，仅增量更新条目列表     │ Toast 提示并自动回退至有效父目录│
└──────────────────────┴────────────────────┴────────────────────┴──────────────────────────────┴────────────────────────────────┘
```
