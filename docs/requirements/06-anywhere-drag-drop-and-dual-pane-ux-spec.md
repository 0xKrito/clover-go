## 三、 四种极限交互态定义

1. **空数据态**：
   - 空文件夹：展示柔和文件夹图标 + “此文件夹为空 — 可将文件拖拽至此，或按 ⇧⌘N 新建文件夹”。该容器全面绑定 Drop / DroppedFiles 热区。
2. **加载等待态**：
   - 目录加载中展示“正在加载文件夹...”，加载完毕后平滑呈现列表，杜绝白屏闪烁。
3. **异常报错态**：
   - 遇到无读取权限（EACCES / EPERM）时，明确呈现“🔒 无权限访问此文件夹”警示卡片，提供“在访达中打开”与“重试”按钮，杜绝谎报为空文件夹。
   - 非法拖拽（父入子死循环、拖入只读压缩包 VFS）在释放前由前置安全拦截器校验并 Toast 友好提醒。
4. **极端数据态**：
   - 侧边栏项过多超出窗口高度时支持平滑垂直滚动 (ui.Scroll) + 分组折叠收起；文件名超长在列表和拖拽预览浮层中单行截断 (SingleLine) 并保留扩展名可见。
