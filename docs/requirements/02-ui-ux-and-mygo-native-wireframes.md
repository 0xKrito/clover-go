## 二、 四种极限交互态定义（强制门禁 1 规范）

### 1. 空数据态 (Empty State)
- **空文件夹**：在主内容区垂直水平居中渲染轻量矢量文件夹插画 + 文案 `“此文件夹为空”` + 副标题 `“可将文件拖拽至此，或按 ⇧⌘N 新建文件夹”` + `[➕ 新建文件夹]` 快捷按钮。
- **搜索/标签过滤无结果**：居中展示放大镜矢量图标 + `“未找到匹配 ‘xxx’ 的文件”` + `[清除搜索条件]` 按钮。

### 2. 加载等待态 (Loading & Non-blocking State)
- **防闪烁延迟加载门限 (60ms Grace Period)**：本地 SSD 绝大多数目录在 `<5ms` 内读完，**严禁在 60ms 内闪现 Loading 骨架屏造成视觉抖动**；仅当大目录或网络盘读取超过 `60ms` 时，才在顶部路径栏右侧显示平滑旋转指示器，并在首屏（前 200 条）抵达后立即允许用户滚动交互，后台继续流式补齐剩余分页。
- **文件复制/移动/压缩耗时操作**：当单次操作耗时 `>200ms` 时，底部状态栏左侧自动浮现内联进度条 `[⏳ 正在复制 42/128 项... 取消]`，主界面浏览与切 Tab **完全不阻塞**。

### 3. 异常报错态 (Error & Recovery State)
- **权限受限目录（如 `/System/Volumes/...` 或无读权限目录）**：主区域不闪退、不留白，渲染带锁矢量图标警示卡 `“无法打开‘xxx’，因为您没有查看其内容的权限”` + `[返回上一级 (⌘↑)]` 按钮。
- **操作失败（重命名非法字符、目标只读、磁盘已满）**：
  - 通过 `c.AddToast` 弹出红色高亮通知（保留 4 秒），精确说明系统底层错误原因；
  - 若是内联重命名失败，**保持编辑框展开并保留用户刚输入的草稿文本**，绝不一棍子打回原形。

### 4. 极端数据态 (Extreme Data & Scale State)
- **10 万级文件大目录（如 `node_modules` 或海量日志目录）**：
  - **视图层**：`ui.Table` 与 `ui.GridView` 严格按视口高度仅实例化屏幕可见的 `20~40` 行节点；
  - **图标/缩略图管线**：仅被当前帧实际调用渲染的条目才会向 `IconPipeline` 发起图标获取请求；采用 **LIFO 视口优先调度 + 最大 6 并发 Worker + 内存 LRU (1024 项) + 磁盘 PNG 缓存**，快速滚动滑过的数万行零系统调用开销。
- **超长文件名与深层路径**：
  - 列表视图文件名采用尾部/中间省略截断，悬停 `ui.Tooltip` 显示完整文件名；
  - 网格视图文件名最多展示 2 行，超出部分省略；
  - 路径面包屑在窄窗口下自动将中间深层节点折叠为 `…` 下拉菜单，保证末尾当前目录名永远完整可见。

## 三、 `mygo/ui` 原生组件与视觉 Token 映射表

| 界面区域 | `mygo/ui` 实现原语 | 原生质感打磨细节 |
| :--- | :--- | :--- |
| **沉浸式顶栏 + Clover 标签栏** | `mygo.TitleBarHidden` + `TrafficLightPosition{X: 16, Y: 18}` + 顶栏 `ui.Row(c).Height(42)` | 左侧预留 `76pt` 红绿灯安全区；活动标签背景与下方工具栏完全同色，非活动标签半透明悬停高亮；右侧空白区挂载 `.DragWindow()` |
| **毛玻璃侧边栏** | `WindowOptions.Vibrancy: mygo.VibrancySidebar` + `c.Root().Background(ui.Transparent)` | 左侧 `200pt` 宽度透出 macOS 桌面壁纸冷暖色调；分组标题采用 `11pt` 半粗体次级色，选中项圆角 `6pt` + 强调色柔和底色 |
| **列表视图 (`FileListView`)** | `ui.Table(c, &tab.TableState, columns)` | 行高紧凑 `28pt`（对齐 Finder 标准行高），斑马纹极弱对比或纯平底色，支持 `DragSelect` 拖选与列头点击排序 |
| **网格视图 (`IconGridView`)** | `ui.GridView(c, &tab.GridState, len(items), cellW, cellH, renderCell)` | 图标区域固定居中正方形 + 4pt 圆角选中底框，文字标签选中时反白高亮（完全复刻 Finder 图标选中态） |
| **右侧预览栏 (`PreviewPane`)** | `ui.Split` 或右侧固定 `260pt` `ui.Column` + `ui/editor` + `ui/markdown` | 顶部居中展示高清图标/图片预览，中部键值对齐展示元数据，底部提供 7 色圆点与快捷动作胶囊按钮 |
| **矢量图标体系** | 复用并扩展 `roxy` 的 `*ui.SVG` 矢量图标库 + `mygo.Shell.FileIcon` | **全面清零 Emoji**，工具栏、侧边栏、空状态全部采用 1.5px 描边 Apple SF Symbols 风格矢量 SVG |
